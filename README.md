# StrayScope project page

Project page for the anonymous submission "StrayScope: Harnessing Adversarial Optics to Mitigate Optical Injection
Threats and Harden Visual Perception Systems" (under review).

The page is static: open `index.html` through GitHub Pages, or serve this folder locally, for example with
`python -m http.server`, and open http://localhost:8000. It loads no third-party scripts, fonts or trackers.

Fonts: Spectral and Libre Franklin, both under the SIL Open Font License (licences in `assets/fonts`).
